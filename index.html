The golden rule

What gets fixed vs. what gets flagged

Every rule below is a small, testable function. Nothing in this list guesses at business meaning — a number is a number until you say otherwise.

ConditionAction
Completely blank rowRemove
Completely blank columnRemove
Leading / trailing / double whitespaceFix
Exact duplicate rowRemove
Valid date in a non-standard formatStandardize to DD-MM-YYYY
Number stored as text ("15,000")Convert to numeric type
Inconsistent header casingStandardize to Title Case
Unparseable date valueHighlight & preserve
Missing required fieldHighlight & preserve
Row that partly repeats another row (half or more of the fields match, but it isn't identical)Flag entire row for human review
Any numeric-looking columnKept as a number — never auto-formatted as currency
